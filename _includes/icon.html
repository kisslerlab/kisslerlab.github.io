Usage: {% include icon.html key=link.icon %} `key` is matched against substrings of the old Font-Awesome class string so the people data files don't need to change. Provenance / licensing (no runtime dependency, no attribution required): - github, google (scholar), twitter (X), bluesky: Simple Icons (https://simpleicons.org), released CC0 1.0 / public domain. - cv (document), email (envelope), school (columns), linkedin (neutral profile): original glyphs drawn for this site.
